# 🧠 MemoryOS

MemoryOS is a local-first semantic document search engine that helps users instantly find information across their documents using AI embeddings and vector search.

## Features

* PDF document indexing
* Semantic search using embeddings
* Keyword search
* FAISS vector database
* Document preview panel
* Multi-folder indexing
* Background reindexing
* Local storage with SQLite

## Tech Stack

* Python
* PyQt6
* SQLite
* FAISS
* Sentence Transformers
